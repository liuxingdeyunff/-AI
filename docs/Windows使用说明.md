# 知序 AI · Windows 11 x64 使用说明

下载 ZhixuAI-Windows-x64.zip，右键选择「全部解压」，进入解压后的文件夹，双击「知序AI.exe」。首次启动请稍候，默认浏览器会打开学习首页。软件内含运行环境和已构建的网页。请完整保留 runtime、app 文件夹。

学习时保留「学习服务运行中」窗口。浏览器标签页可以关闭，再次双击软件会重新打开原学习界面。点击服务窗口中的「确定」或关闭该窗口，会停止本地服务。默认端口被使用时，软件会自动选择空闲端口。

学习数据在 %LOCALAPPDATA%\ZhixuAI\learning.db。升级时关闭旧版本，解压新包并启动即可。第一版用户可以在旧版「个人进度」导出进度后恢复，也可在新旧程序均已关闭时，将旧版 data\learning.db 复制到上述尚未使用的数据目录。请先备份已有数据库。

进入「资料库」，导入「示例资料」中的原创 PDF，可按页查看讲义。选择「开始诊断」测试当前水平。错题加入复习计划，可进入先修讲义，或继续针对性练习。没有上传的教材不会被用作教学来源。

启动失败时先检查是否完成全部解压，磁盘是否有剩余空间，当前用户是否能写入个人数据目录。打开资源管理器，在地址栏输入 %LOCALAPPDATA%\ZhixuAI 可查看 startup.log 和 launcher.log。仅从受信任的项目分支、构建产物或 Release 下载。当前 EXE 未进行商业代码签名。



## 教学模式

在资料库的「教学模式」中可以选择本机 Ollama 已安装的模型，或配置自己的 DeepSeek 模型 ID 和 API Key。云端配置只保留到本次程序退出。选择资料片段后可预览发送内容；云端调用可能计费。离线学习无需模型。

答题时可填写步骤，提交后点击「复盘思路与针对性变式」。确认采用的方法后，变式会根据后续答题结果调整难度。符号题由 SymPy 校验，模型生成的解释和开放练习需要结合原文核对。
