## Windows 便携版与可追溯 AI 教学

本 PR 基于 main 的 58893f7。普通用户解压 Windows x64 包后双击知序AI.exe。运行环境、SymPy、pypdf、前端和公式字体均随包交付。SQLite 数据按 Windows 用户保存。

本机 Ollama 可由资料库选择。选定片段生成章节化研读单元、来源引用、建议先修和开放练习。符号答案由 SymPy 校验。复盘页保存学生步骤、提示次数、方法选择、变式结果和经授权的模型追问。未启用模型时也可完成核心流程。

### 复验

Windows 工作流执行干净构建、解压 EXE 测试和 Playwright 浏览器验收。另有真实 Ollama 集成测试及隔离的数学、资料定位和备份恢复测试。请查看本分支的验收报告与实际截图。此 PR 待人工审查。
